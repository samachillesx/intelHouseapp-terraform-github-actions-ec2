# IntelHouseApp

A full-stack web application deployed on AWS EC2
using Docker, Terraform and GitHub Actions.

## Technology Stack

### Frontend
- React
- Vite
- CSS / Tailwind CSS

### Backend
- Node.js
- Express.js
- REST API

### Database
- PostgreSQL

### DevOps and Cloud
- AWS EC2
- Terraform
- Docker
- Docker Compose
- GitHub Actions
- GitHub Container Registry
- AWS IAM
- GitHub OIDC
- AWS Systems Manager

## Architecture

React Frontend
       |
       v
Express Backend API
       |
       v
PostgreSQL Database

## Deployment

Application containers will be deployed
to an AWS EC2 instance using Docker Compose.

GitHub Actions will automate testing,
container builds, image publishing and deployment.

Terraform will provision the AWS infrastructure.
